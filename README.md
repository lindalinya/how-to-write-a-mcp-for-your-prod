# How to Write a MCP for Your Product

一套从真实产品中逆向拆解出来的 **CLI + MCP 设计手册**。

![三出口 / 一内核](assets/architecture.svg)

内容来自对一套真实产品的 CLI（321 个 API 端点、524 个命令节点）与 MCP 服务器（118 个工具）的分析，
覆盖从规格模型、传输层、本地存储、输出管线、MCP 工具设计，到学习系统、版本兼容、安全与可运维性的完整设计。

## 开始阅读

→ **[design-guide/README.md](design-guide/README.md)**

## 适合谁

- 想给自家产品做一套 CLI / MCP 的工程师
- 想知道"321 个接口怎么不写崩"的技术负责人
- 想评估 AI 工具链安全边界的评审者

## 说明

- 分析对象为公开发布的二进制包，未接触原始源码。
- 文档中明确区分了**实测事实**（二进制元数据、运行时行为）与**设计推断**。
- 代码骨架为按设计意图重写的示意代码，不是原始实现。
